# 已确认的交互练习题库

`evals/bobbybs-draft-quiz/practice/` 保存维护者分档草案、用户确认、导出件与测评准备。它不是 BP decide 的答案知识；只有独立练习评分服务消费确认后的 `bank.json`。

1. 草案同时保留作者历史名单、机制解释、新增分档和未解分支。每个待启用题至少包含 correct / reasonable / poor 三档，条件解不能静默去掉条件。
2. 用户确认绑定 `questions.draft.jsonl` 的 SHA-256，见 `approval.json`。用户已确认 2026-09-20 草案，暂缓第 41/44/47 题；不重复索要这版确认。
3. `export_bank.py` 校验确认哈希并导出 53 题。后续变更题面/选项/标签须形成新审阅版本，不能覆盖已确认文件后自动换哈希冒充已确认。
4. 应用只安装哈希匹配的导出件；题序、seed、游标、题卡实例、用户作答属于应用层，不能写回知识库或临时 outputs。
5. 多正确分支允许超过 3 个，应用每次轮换最多 3 个，加中间和反面选项形成 3–5 项；双选题按组合评分。作者名单外的合理方案不自动判错。
6. 前端与出题工具在作答前不能接触标签或答案解释。模型回归只能接触 `inputs.options-only.jsonl` 与中性 runtime 检索结果，评分侧单独读取标签。
7. 用户已要求 BP skill / 题库自洽回归先记为 TODO。本地结构校验、已确认标签和练习评分成功均不代表该回归通过；见题库 `practice/TODO.md`。

原 `cases.calibrated.jsonl`、原始字幕/截图及其 gold 状态不因练习上线而改变。知识实体不能为迎合练习标签而新增没有来源的对位结论。
